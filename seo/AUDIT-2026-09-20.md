## Embargo (keep until Brad says launch)

Working as designed:

- Every HTML page has static `noindex, nofollow`.
- `dsc-header.js` injects the same tag if a page ever forgets it.
- Netlify sends `X-Robots-Tag: noindex, nofollow` on all URLs (including 404s).
- `pages/robots.txt` is `User-agent: *` / `Disallow: /` with no Sitemap line.
- Splash overlay still injects from the header (bypass `?preview=1`).
- Draft sitemaps live only under `seo/` (`sitemap.xml` lastmod still 2026-08-31 — regenerate on launch day).

Do **not** copy `seo/sitemap.xml` into `pages/` until splash comes down.

### Google catch (decision for Brad)

`site:digitalsoulcraft.org` still returns home, about, wiki, essays, outlines, and more, with **full library copy** in the snippets — not the splash.

`Disallow: /` stops Googlebot recrawling. `noindex` only works if the bot is allowed to fetch the page. Pages indexed before the embargo can sit in Google because the bot is now forbidden from coming back to see the noindex tag.

If the goal is “do not appear in Google until we announce”:

1. Keep meta robots + `X-Robots-Tag` as `noindex, nofollow`.
2. Change `robots.txt` to **allow crawl** (`Allow: /` or empty Disallow). Still no sitemap.
3. Request recrawl / use Removals in Search Console if you have it.

If the goal is “do not spend crawl budget, we do not care about leftover listings,” leave `Disallow: /`. That is the current state.

## Remaining on-page gaps

### 1. Meta descriptions — done

283 / 283 real pages have a unique description. `/contact/` is no longer short (now ~103 chars). `/about/` is no longer over-long (now ~154). Wiki 160-character mid-sentence cuts are rewritten.

`/bookshop/` still *describes a collection* while the page is Coming Soon — rewrite that description to match, or keep the page noindex after launch until stock exists.

`/essays/language-is-architecture/` and many paper pages are still over 160 characters. Complete sentences, so Google will clip rather than lie; front-load the claim if you trim.

### 2. Canonicals and Open Graph text — done; images still missing

Every real page has an absolute canonical and matching `og:url` (trailing slash). Homepage is `https://digitalsoulcraft.org/`. Language-is-architecture OG tags use `property=` now.

Zero pages have `og:image`. Zero have `twitter:card`. Shares will look like a bare URL until a default 1200×630 exists (stamp / Ghibli plate) and is referenced sitewide, with per-essay images where James already drew them.

### 3. Titles — unique, often too long

124 titles are over 60 characters; 74 over 70. SERP truncation is ~50–60.

Worst are field-guide papers (paper title + authors + year + “Digital Soulcraft”), up to 135 characters:

- `/fieldguide/papers/2605.04097/` — 135
- `/fieldguide/papers/2605.30232/` — 130
- `/fieldguide/papers/2505.13969/` — 126

Wiki titles put the distinctive phrase first (good) then a subtitle then “Digital Soulcraft Wiki” (pushes them to 90–100). Trim the subtitle or drop the brand suffix on long ones.

### 4. Headings

- `/contact/` — h1 then h3 (Primary / Or Use This Form) then h2 (Send a Message). Promote those h3s to h2, or wrap them as labels.
- `/outlines/` — card titles are h3 with no h2 in between. Use h2 for card titles.
- `/outlines/crystallization-of-self/` — flagged only if a later jump exists; the visible outline is h1→h2→h3→h4, which is fine.
