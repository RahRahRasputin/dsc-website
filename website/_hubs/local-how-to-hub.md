# 🛠️ Local How-To

> How do you actually run this locally? Practical guides to inference, setup, deployment, and optimization on your own hardware.

## What This Silo Covers

Local How-To is the **practical operations silo**: step-by-step guides for running models on your own hardware. It covers inference servers, containerization, GPU management, model formats, benchmarking, and the real-world constraints of local deployment.

This is where we learn:
- **Model inference & serving** — Running models with Ollama, llama.cpp, and other tools
- **Local infrastructure** — Docker, reverse proxies, networking, remote access
- **Hardware optimization** — GPU selection, VRAM management, thermal and power considerations
- **Model evaluation** — Benchmarking, profiling, cost analysis
- **Practical integration** — Building on local models, RAG systems, Obsidian integration
- **Formats & quantization** — GGUF, SafeTensors, EXL2, trade-offs in practice
